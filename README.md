# Bank Marketing Machine-Learning Project

This project predicts whether a bank customer will subscribe to a term deposit.

The project compares a majority-class baseline, Logistic Regression and
Random Forest.

Logistic Regression achieved the highest validation Average Precision
and was selected as the final model.

## Files

- `a2_bank_marketing.ipynb` contains the machine-learning work.
- `journal.md` contains the project report.
- `requirements.txt` contains the required Python packages.

## Running the notebook

Create and activate a Python environment.

Install the packages from `requirements.txt`.

Open `a2_bank_marketing.ipynb` in VS Code, select the Python kernel and
click Run All.
